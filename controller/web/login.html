espDNS

Log in

No password is set. Until one is, the controller is read-only: its pages show the nodes, and it takes no actions. Set the password once, from the host:

docker compose run --rm --entrypoint /espdns espdns-controller passwd -data /data

Run it in controller/. That runs espdns passwd in the controller's image with the data directory mounted; it asks for the user name (your choice; -user gives it), then the password twice, without echo, and keeps an argon2id hash in auth.json (mode 0600). Outside Docker: ./espdns passwd -data data. Then reload this page.

Go on, read-only
